Open Knowledge Format publishing

Turn structured Markdown into navigable knowledge systems.

Kiso is a publishing engine for OKF. It builds static HTML websites from Markdown knowledge bases while preserving the original files, making the same content practical for readers, maintainers, and AI agents.

What Kiso does

OKF, the Open Knowledge Format, is a way to organize Markdown files so knowledge can be described, validated, linked, and reused consistently. Kiso takes those OKF files and turns them into a website that is easy to browse without losing the source structure.

For humans

Readable pages, navigation, styles, and static files that can be opened locally or hosted on a standard HTTP server.

For AI agents

Preserved Markdown sources and predictable structure, so generated websites remain traceable to the knowledge base.

Static output

The generated site is made of HTML, CSS, JavaScript, assets, and Markdown files. It does not require a backend.

OKF first

The engine is designed around knowledge bundles rather than generic web pages, closer to Hugo but focused on OKF.

The build command

The build command reads an OKF source directory and writes a complete static website to a destination directory.

  • Source: a folder containing OKF Markdown files.
  • Destination: a generated website ready to publish.
  • Result: HTML pages, copied assets, navigation, and original Markdown files.

Example command

./applications/kiso-cli/target/kiso-cli build \
  --source=examples/kb-google-example \
  --destination=website/examples/kb-google-example
