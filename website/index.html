Open Knowledge Format

Publishing engine for Open Knowledge Format

Kiso provides two applications built around Open Knowledge Format (OKF) bundles. kiso-cli validates and publishes them as static websites, while kiso-mcp-server gives MCP-compatible AI applications direct access to their knowledge.

View an example Download Kiso

Build a site

kiso-cli build \
  --source=examples/kb-google-example \
  --destination=public

The generated directory can be opened locally or published on any HTTP server.

Publish your OKF bundle as a static website

kiso-cli

The command-line application provides two commands: check validates an OKF bundle and build generates its static website. The build output keeps the original Markdown files alongside the generated HTML pages (with sitemap.xml, llms.txt, search engine, download button links...).

Command

What check does?

The check command validates the Markdown files in an OKF bundle and reports formatting or structural errors before publication (it also reports broken links as warnings).

source Any OKF bundle directory like examples/kb-google-example

Command

What build does?

The build command generates a static website from an OKF bundle, including the original Markdown files, generated HTML pages, sitemap.xml, llms.txt, search engine and download bundle links.

source Any OKF bundle directory like examples/kb-google-example
destination public or any other directory

GitHub Action

Use in GitHub CI

You can use kiso-cli in a GitHub Action to automatically check, build, and publish your OKF bundle to GitHub Pages or any other static hosting service. 

 - name: Build with Kiso
   uses: oak-invest/kiso/applications/kiso-cli-action@v0.2.4
   with:
    command: build
    source: examples/kb-google-example
    destination: public/kb-google-example
01

Browse

Readers get a structured static website with navigation and readable pages.

02

Inspect

Each page can link back to its Markdown source for review and reuse.

03

Publish

The result is plain static output that can be hosted locally or over HTTP.

Give AI access to your OKF throw MCP

kiso-mcp-server

This second application starts a Model Context Protocol (MCP) server over an OKF bundle. It does not generate a website: it lets an MCP-compatible AI application access the knowledge contained in the bundle directly.

Search concepts

Find concepts in the OKF bundle with the search MCP tool.

Read concept content

Retrieve a concept's Markdown content with the get_concept_content MCP tool.

kiso-mcp-server \
  --source=examples/kb-acme-example-v0.2

MCP client

Connect the MCP-compatible AI application to the server endpoint (example: http://localhost:8080/mcp), then let it discover and call the available knowledge tools.
